# GSoC Workshop

Add your name to `AUTHORS.md` and open your first pull request.

## 1. Fork

Click **Fork** at the top right of this repository, then **Create fork**.

## 2. Clone

```bash
git clone https://github.com/<your-username>/GSoC-IMG-Workshop.git
cd GSoC-IMG-Workshop
```

**VS Code:** `Ctrl+Shift+P` (`Cmd+Shift+P` on Mac) → **Git: Clone** → paste your fork's URL.

## 3. Add your name

Open `AUTHORS.md`, add your name on a new line at the end, and save.

```
Your Name
```

## 4. Commit

```bash
git add AUTHORS.md
git commit -m "Add <Your Name> to AUTHORS.md"
```

**VS Code:** Source Control panel (`Ctrl+Shift+G`) → click **+** next to `AUTHORS.md` → type a message → **Commit**.

## 5. Push

```bash
git push origin main
```

**VS Code:** Click **Sync Changes** in the Source Control panel.

## 6. Create a Pull Request

1. Open your fork on GitHub and click **Contribute** → **Open pull request**.
2. Check that the base repository is `sommye-ctr/GSoC-IMG-Workshop` (`main`).
3. Add a title, e.g. `Add <Your Name> to AUTHORS.md`, and click **Create pull request**.

**VS Code:** Install the **GitHub Pull Requests** extension → open its panel → **Create Pull Request**.
